📊 Walmart Sales & Profit Analysis Dashboard | Microsoft Power BI Project
I'm excited to share my latest Data Analytics project – Walmart Sales & Profit Analysis Dashboard, developed using Microsoft Power BI! 🚀

🎯 Project Objectives:
To transform raw retail sales data into meaningful business insights and help understand sales trends, profitability, discounts, and regional performance.
📈 Key Dashboard Features:
🔹 Profit & Discount Analysis
Analysed profit and discount across product categories.
Compared actual profit against the target.
🔹 Sales Performance
Compared sales across Technology, Office Supplies, and Furniture.
Analysed sales by sub-category.
🔹 Profitability Analysis
Identified profitable and loss-making sub-categories.
Compared profit across different shipping modes.
🔹 Regional & State Analysis
Analyzed profit across different US states.
Used interactive region filters (Central, East, South, and West).

💡 Key Business Insights:
This dashboard helps identify:
Which product categories generate higher sales.
Which sub-categories contribute to losses.
How discounts relate to profitability.
How regional performance differs across states.
Which shipping modes generate higher profits.
